# carsim_fullcar 조향각3.5° 추가150조건

사용자 요청으로 조향 명령3.5° 조건만 추가합니다. 원래1~1050번과 기존 결과는 보존하고, 새 조건은 **1051~1200번**으로 뒤에 붙입니다. 전체 조건 합계는1200개이며, 원래 마모별210조건에30개씩 추가됩니다.

- 마모5패턴: [0,0,0,0], [25,25,0,0], [50,50,25,25], [0,0,25,25], [25,25,50,50].
- 속도50:10:100 km/h × 마찰계수[0.9,0.8,0.7,0.6,0.5] × 조향3.5° = 패턴별30조건.
- 추가 ID순서는 마모→속도→마찰계수입니다. 추가 범위의 condition_id는1~30입니다.

원래result/1050회를 만든34상태 모델과 동일한 물리 소스·보정·데이터·두 MEX 바이트를 사용합니다. GNU Octave10.3.0에서 실행하며, 자체 트림의 실제 평균 전륜 조향각으로 외부 정적MF H를 계산합니다. 61×121점, RK4 0.0005초, 관측0.001초, 5·10초, 마지막 닫힌1초의7관측값 회복, 전체 경로H·물리 조건, 별도로 적분한 셀 중심 판정은 기존 배치와 같습니다. 이미지를 포함합니다.

기존1050배치의 실행 중인 코드·컨텍스트·진행률·서명은 변경하지 않습니다. 새 준비·감사·실행 코드는 ../code_steer35/에 분리하고 새 입력 서명을 기록합니다. 이150조건은 기존result/에 원본 주행 파일이 있는 것으로 표시하지 않습니다.

이 환경의 기존1~450 계산이 검증·최종 업로드를 마치고 프로세스 및 계산 잠금을 해제하면 추가150조건 전체를 이어 실행합니다. 사용자가 추가분 인계를 취소하여1051~1200번은 원래 대화가 전담합니다. 다른 대화의451~1050 작업은 변경하지 않습니다. 외부 큐와 복구 도구는 /workspace/work에 있으며, 계산 결과는 main에 조건마다1개씩 업로드합니다.

```sh
python stable_region/code_steer35/run_steer35_batch.py \
  --runtime-wrapper /workspace/work/octave-runtime/run-in-env.sh \
  --octave octave-cli --skip-prepare \
  --start-id 1051 --end-id 1200 --shard-name steer35_1051_1200 \
  --publish-branch main --publish-every 1
```

실제 진행률은 shards/steer35_1051_1200/progress.json에서 N/150으로 확인합니다. 입력 준비 완료는 안정영역 계산 완료를 뜻하지 않습니다. 원래1050개와 합쳐1200개가 검증되기 전에는 전체 완료를 주장하거나 전체LUT를 최종화하지 않습니다. 이 폴더의 LUT는 추가150조건만 포함합니다.
